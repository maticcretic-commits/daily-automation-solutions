# Daily Automation Solutions

One solved client problem per day, taken from real freelance gigs on Upwork and Freelancer.

Each folder under `solutions/` contains:
- **Working code** (not stubs) for a representative client automation problem
- **Passing tests**
- **A README** explaining the problem, the approach, and how to run it

Rotation: n8n workflows → AI chatbots & voice agents → Excel & Power BI → lead capture & CRM → WhatsApp automation.

These are portfolio demos — built from the gig brief, open for review, never connected to a real client engagement.
