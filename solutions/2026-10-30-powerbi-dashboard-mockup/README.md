# Demo Traders — Power BI dashboard demo (demo proof #3 of 3)

An honest, build-ready package for a Power BI dashboard demo using
synthetic data. Fictional business "Demo Traders". No real clients, no real
sales, no delivered dashboard is claimed.

## What this demo proves

- Nitesh can define a small, clean dataset (star schema), specify the
  measures a sales dashboard needs, and lay out the three report pages
  (overview, breakdown, target tracking) — with the numbers in the visual
  preview computed exactly from the data.
- It does **not** prove a dashboard was built in Power BI Desktop, and it
  does not claim SQL, DAX, or Power Query proficiency: the DAX measures
  are written spec, untested in Power BI (see Limitations).

## Files

| File | What it is |
|---|---|
| `sales.csv` | 600 synthetic order lines |
| `targets.csv` | 48 synthetic category × month targets |
| `DATA_DICTIONARY.md` | Every column, type, meaning, generation method |
| `POWERBI_SPEC.md` | Tables, relationships, DAX measures (SPEC), visuals, build steps |
| `index.html` | Static visual mockup (3 pages, inline SVG charts, no external CDN) |
| `gen_data.py` | Deterministic generator (seed 42) + headline numbers + mockup builder |
| `CHECKS.txt` | Row counts and headline totals, computed by the generator |
| `test_demo.py` | Tests: data loads, no nulls, totals match, mockup contains the numbers, no Power BI file claimed |
| `VERIFY.txt` | Recorded test output |

## How to regenerate the data

```sh
python3 gen_data.py
```

Python 3 standard library only. Deterministic: re-running produces
byte-identical CSVs, CHECKS.txt, and index.html.

## How to run the tests

```sh
python3 test_demo.py
```

All tests must pass. Output is recorded in `VERIFY.txt`.

## How to build the real Power BI file from the spec

1. On a Windows machine with Power BI Desktop, follow `POWERBI_SPEC.md`
   §4 step by step: import the two CSVs, add the month column, create
   the relationships, create the six DAX measures exactly as written,
   build the three pages.
2. Check the page-1 KPI cards against `CHECKS.txt` (Total Sales
   Rs 7,189,354.50; Total Qty 4,030; Avg Discount % 5.73%; Sales vs
   Target % 124.84%; Top Category Furniture).
3. Save the work in Power BI Desktop — the resulting saved file is the
   Power BI file format. No such file is included in this package, and
   none should be claimed until this build is actually done and checked.

## Limitations — read before showing this to anyone

- The HTML page is a **mockup — visual preview only, not a Power BI
  file**. It was generated by a Python script from the CSVs, not built
  in Power BI Desktop. Its header says so.
- The DAX measures in `POWERBI_SPEC.md` are **written spec, untested
  in Power BI**. They may need small corrections when built for real.
- **SQL and Power Query were not used** to produce this package and are
  not claimed as evidenced skills here.
- **Synthetic data only.** No client work, no named clients, no real
  sales. The fictional salesperson names are invented.
- Do not present this package as a delivered client dashboard or as
  proof of Power BI Desktop experience. Present it as what it is: a
  reproducible synthetic dataset, a build spec, and a visual preview.
